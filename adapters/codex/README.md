# Codex Adapter

Recommended install through the open agent skills CLI:

```bash
npx skills add 1GMedia/attract-signal-skill --skill attract-signal -g -a codex
```

Manual fallback from this repository:

```bash
./install.sh codex
```

Destination:

```text
~/.codex/skills/attract-signal
```

Use the same `skills/media/attract-signal/SKILL.md` and bundled scripts as every other agent.
